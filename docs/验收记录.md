- 历史触发事件不读取未来事实；追加生成新版本，旧报告不变。
- 动态路由改变真实参与角色，跳过角色不计入有效意见分母；固定全员模式调用四角色。

- 取消和超时不保存成功报告；重启将 queued、running、cancel_requested 三种未终态各标记为一次 `process_interrupted`。
- 在最终 `run.completed` 写入时注入 SQLite 错误，报告和两个完成事件一起回滚；解除故障后可成功重试。
- 四个未完成任务后，第五个请求被拒绝且不新增记录；取消后容量恢复。
- 模型结构化输出、重试与真实请求计数、错误脱敏、配置冻结、秘密不入报告/审计，以及跨来源写入拒绝。

模型测试使用 `httpx.MockTransport`，没有连接真实模型服务，也没有付费模型请求。通过这些测试不能推断具体模型已兼容。

## 构建提示与验收边界

生产 JavaScript 主文件为 500.40 kB，gzip 150.19 kB；Vite 提示单文件略超过 500 kB。另有 Zod 依赖注释的 Rollup 标注提示，构建已自动移除无法解释的注释。Python 的一条提示来自 Starlette TestClient 对当前 httpx 适配的弃用。以上均未阻止测试或构建，但后续依赖升级与按页面拆包时应处理，不通过扩大阈值隐藏提示。

当前未验收：真实模型连通性和用量、外部公开数据导入、医学语义正确性、独立标注与正式对照/消融实验、大规模性能、真实移动设备与其他浏览器、认证及公网部署。浏览器移动端验收使用视口模拟。

取消和总运行超时在流程边界生效，无法立即撤回已发出的同步模型请求；本地服务要求单 Uvicorn worker。重跑保留病例版本和工作流选项，但模型设置采用重跑时的当前值。证据存在与逐字段匹配只证明输入一致性，不证明临床结论正确。

下一阶段按 [技术方案与开发计划](技术方案与开发计划.md) 推进真实模型小样本联调、可追溯数据导入和独立实验，完成后再写论文。
